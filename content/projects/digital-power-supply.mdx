## 项目概述

本项目为 **STM32 数控直流电源 + 线性电子负载一体化平台**，由两大独立功能模块组成，配套数字测控系统，实现电源输出程控、负载程控、电压/电流/温度采集、自动保护与模式自动切换。主要用于直流电源测试、锂电池充放电、电子器件老化测试等场景。

### 核心指标

| 参数 | 电源模块 | 负载模块 |
|------|----------|----------|
| 输出电压 | 0~12V | 0~20V（输入范围） |
| 输出电流 | 0~2A | 0~2A |
| 额定功率 | 24W | 40W |
| 工作模式 | CV/CC 自动切换 | CC/CV/CR/CP |
| 控制方式 | DAC 数控 + ADC 反馈 | DAC 数控 + ADC 反馈 |
| 采样电阻 | 1Ω/10W | 0.1Ω 开尔文四线 |
| 电流采样放大 | 1.5 倍差分 | 15 倍差分 |

### 系统架构

整机采用 **模拟运放负反馈闭环 + 数字 DAC/ADC 混合控制** 架构：

```
┌─────────────────────────────────────────────────────┐
│                    STM32 主控                         │
│              DAC 设定 ← → ADC 采样                    │
└─────────────┬───────────────────────┬────────────────┘
              │                       │
     ┌────────▼────────┐     ┌───────▼────────┐
     │  电源 CV/CC 环路 │     │  负载恒流环路   │
     │  P-MOS 调压     │     │  N-MOS 可变电阻 │
     │  二极管或门切换  │     │  15 倍差分放大  │
     └─────────────────┘     └────────────────┘
```

## 模块一：0~12V/2A 数控 CV/CC 线性稳压电源

### 2.1 整体架构

整机分为六大模块：

- **输入保护电路**：NTC + PPTC + 反接防护 + TVS 四层保护
- **功率主回路**：P-MOS 串联线性调压
- **CV 恒压环路**：运放负反馈调压
- **CC 恒流环路**：差分放大 + 运放限流
- **基准源电路**：TL431 双路精密基准
- **数字测控电路**：DAC 设定 + ADC 采样

### 2.2 输入保护电路

16V 输入端采用 **四层防护**，顺序不可颠倒：

| 层级 | 器件 | 作用 |
|------|------|------|
| 1 | MF72 5D11 NTC | 抑制开机浪涌电流 |
| 2 | JK-MSMD200-24V PPTC | 2A 级过流/短路自恢复保护 |
| 3 | SS34 肖特基 | 电源反接防护 |
| 4 | SMBJ24A TVS | 吸收高压浪涌、钳位异常尖峰 |

### 2.3 CV 恒压环路

**核心调压原理**：DAC 设定基准电压 → 运放同相端；输出电压经 30kΩ+10kΩ 分压（分压比 1/4）反馈至运放反相端。运放输出驱动 P-MOS 栅极，通过调节管压降稳定输出电压。

**对应关系**：
- 目标输出 10V → 分压反馈 2.5V → DAC 设定 2.5V
- 满输出 12V → DAC 设定 3.0V

**环路补偿**：运放反相端与输出端并联 **47pF C0G/X7R** 高频瓷片电容，做密勒相位补偿，防止高频振荡。

### 2.4 CC 恒流环路

**电流采样**：1Ω/10W 精密功率电阻，满流 2A 时采样电压 = 2V

**差分放大**：增益 1.5 倍，放大后电压 = 3V，直接匹配 DAC 满量程

**调节逻辑**：
- 电流偏大 → 反馈电压升高 → 运放输出抬高 → 电流回落
- 电流偏小 → 反馈电压降低 → 运放输出降低 → 电流抬升

### 2.5 模式切换：二极管或门

CV、CC 两路运放输出各串一支 SS34，阴极共接构成 **低电平优先或门**：

- **正常恒压**：负载电流未超限，CC 运放输出高电平，二极管截止，CV 环路主控
- **恒流切换**：电流达设定值，CC 运放输出被拉低，二极管导通，接管栅极驱动

**自动无缝切换，无需额外逻辑控制。**

### 2.6 关键设计规则

| 规则 | 说明 |
|------|------|
| 栅极驱动 | 只串电阻，全程不并对地电容，防止运放自激 |
| 补偿电容 | 47pF 为 CV/CC 环路专用，不可改容值、不可替换大容量 |
| 环路外部 RC | DAC 前端可用 1kΩ+100nF，允许大容量 |
| 环路内部 RC | 仅使用 pF~nF 级小电容，最大不超过 1nF |
| 地系统 | 功率地/模拟地/数字地三区分离，单点共地 |

## 模块二：0~2A/20V/40W 线性电子负载

### 3.1 核心工作原理

IRF540N 工作在 **可变电阻区（线性区）**，栅源电压决定漏源等效电阻：

- Vgs 升高 → 等效负载减小 → 负载电流增大
- Vgs 降低 → 等效负载增大 → 负载电流减小

配合运放负反馈闭环稳定电流，STM32 输出 DAC 模拟电压作为电流设定基准，实现数字程控恒流。

### 3.2 高精度电流采样（15 倍差分放大）

原单端采样电压仅 0~0.2V，分辨率低；升级为 **15 倍差分放大电路**，放大后电压 0~3V，完美匹配 MCU 0~3V DAC/ADC 量程。

**差分增益**：G = 1 + 14kΩ/1kΩ = 15 倍

**电压对应关系**：0~2A → 0~0.2V（采样）→ 0~3V（放大后）

### 3.3 运放恒流控制环路

- 运放同相端：接入 STM32 DAC 设定电压
- 运放反相端：接入差分放大后的采样电压
- 补偿电容：**220pF C0G/X7R**（电子负载专用，应对大容性负载与强干扰）

**闭环逻辑**：负载波动时，运放自动调整 MOS 栅极电压，改变等效负载电阻，维持电流恒定。

### 3.4 辅助保护电路

| 保护类型 | 实现方式 |
|----------|----------|
| 输入保险丝 | 3A 慢熔保险丝（防短路） |
| 浪涌保护 | SMBJ24A TVS 管 |
| 防反接 | 肖特基二极管串联主回路 |
| 温控保护 | 10k NTC + ADC 采集，超标时关断负载 + 风扇启动 + 蜂鸣报警 |

## 整机统一通用设计规范

### 4.1 三类地系统划分

| 地类型 | 承载内容 | 连接规则 |
|--------|----------|----------|
| 功率保护地 | MOS、采样电阻、主回路与模拟地单点共地 |
| 模拟信号地 | 运放、差分电路、DAC/ADC、TL431 | 与数字地单点跨接 0Ω 电阻 |
| 数字地 | STM32、晶振、按键、指示灯 | 三块地仅一处总交汇点 |

### 4.2 RC 滤波参数区分（核心红线）

| 位置 | 参数 | 说明 |
|------|------|------|
| 环路外部（DAC/PWM 输出） | 100nF / 1μF | 允许大容量，侧重滤除数字噪声 |
| 差分运放输入端 | 禁止加 RC | 避免破坏差分共模抑制比 |
| 差分运放输出端 | 1kΩ + 100pF~1nF | 电容最大不超过 1nF |
| 运放驱动功率管链路 | 只串电阻 | 全程不并对地电容 |

### 4.3 运放密勒补偿电容区分

| 应用 | 补偿电容 | 原因 |
|------|----------|------|
| 数控电源 CV/CC 运放 | **47pF** | 隔离完善、干扰小，兼顾速度与稳定 |
| 电子负载恒流运放 | **220pF** | NMOS 容性负载大、干扰强，优先保证稳定性 |

**两者不可互换！**

## 布线 & 接线通用规范

- **功率走线宽度 ≥ 2mm**，走线尽量短，降低铜皮压降
- **IRF540N 必须加装散热片 + 导热硅脂**，40W 满载建议搭配强制风冷
- **采样电阻采用开尔文四线接法**：粗铜皮走大电流，独立细引线引出采样信号
- **差分两路输入电阻严格对称**，保证共模抑制能力
- **去耦电容**：运放、TL431、STM32 电源引脚就近放置 0.1μF 陶瓷电容

## 联合调试流程

1. **单独调试数控电源**：空载 → 轻载 → 满载，验证 CV/CC 切换、电压/电流精度
2. **单独调试电子负载**：空载 → 逐步加流，验证恒流精度、温控、保护功能
3. **联机测试**：数控电源输出接入电子负载，全档位联动测试
4. **长时间老化**：满载联合运行 30min 以上，监测温升、稳定性、保护逻辑
