## 一、导体的阻抗：直流 vs 交流

同一根导体在直流、低频和高频情况下的阻抗差异显著。**增大导体直径对减小直流电阻有效，但对减小交流阻抗作用有限**。

在 EMC 中，减小交流阻抗的有效办法是**将多根导线并联**。

## 二、导体的电感与趋肤效应（P175-P176）

### 趋肤效应（Skin Effect）

> 交变电流会在导体内部感应出涡流，涡流会抵消导体中心的电流，迫使电流只走导体表层。频率越高，趋肤深度越小，有效导电面积越小，交流电阻越大。

![趋肤效应与导线电阻 — P175](/images/uploads/pcb-grounding/p175-skin-effect.jpg)

### 直流电阻

```
R_DC = ρ * l / S
```

- ρ：导体电阻率（Ω·m）
- l：长度（m）
- S：横截面积（m²）

**圆导线**：`R_DC = ρ * l / (π * a²)`

**扁平导体（PCB走线）**：`R_DC = ρ * l / (w * t)`

### 交流电阻

```
R_AC = K * R_DC * √f
```

交流电阻与工作频率的平方根成正比。

### 频率对有效导电面积的影响

| 频率 | 有效利用 | 功率热耗 |
|---|---|---|
| 1MHz | 100%，无趋肤效应 | 无额外热 |
| 10MHz | 约60%有效 | 40%转化为热 |
| 100MHz | 约19%有效 | 急剧恶化 |

### 铜导线电阻参考值

- 1oz 铜：ρ = 1.724×10⁻⁶ Ω·cm，一个正方形电阻 ≈ 0.45 mΩ/square
- 键合线（1mil 金线）：单位长度电阻约 0.8~1.2 Ω/in
- 关键参考：一个 24-bit ADC 的最低有效位 = 298 nV（任何微小的压降都可能影响精度）

**具体数值举例**：一条 1in 长的 1/2 oz 铜导线（7mil 宽），流过 10μA 电流产生的压降为 1.3μV。

> 设计启示：高频或精密 ADC 电路中，导线电阻产生的压降不可忽略。

## 三、导体的电感计算（P176）

### 圆截面导体电感

```
L = 0.2 * l * [ln(4.5 / d) - 1]   (单位：μH)
```

- l：导体长度（m）
- d：导体直径（m）
- 电感与导体长度成正比

### 扁平导体条电感（PCB 走线适用）

```
L = (μ0 * l) / (2π) * [ln(2l / (w + t)) + 0.5 + 0.2235 * (w + t) / l]   (单位：μH)
```

- w：走线宽度
- t：走线厚度

![导体电感与导线电阻图表 — P176](/images/uploads/pcb-grounding/p176-conductor-inductance.jpg)

> 宽度 w 增大 → 电感减小；厚度 t 增大 → 电感也减小。
> **但宽度增大比厚度增大产生的电感减小量要大得多**——PCB 设计中应优先加宽走线而非加厚铜箔来降低电感。

### 多根导线并联的电感

```
L_parallel = (L1 + M) / 2
```

- L1：单根导线的电感
- M：两根导线之间的互感

当两根导线相距较远时，互感 M 很小，总电感约为单根导线电感的一半。

![接地导线阻抗与多根导线并联 — P176](/images/uploads/pcb-grounding/p176-parallel-ground.jpg)

> 设计原则：地线尽量加粗和缩短，降低公共阻抗。引线电感与长度成正比、与直径的平方根近似成正比（直径增大 4 倍，电感才减小一半）。

## 四、地弹噪声（Ground Bounce）

> **根源**：接地电感过大，当瞬间大电流流过接地引脚时，地参考电位发生偏移。

**原因链路**：

1. 开关电路产生瞬间大电流
2. 电流流经存在电感的接地路径
3. 电感产生电压降 `V = L * di/dt`
4. 地参考电位偏移 → 系统不稳定、EMI 超标

**抑制方法**：

- 缩短地线路径、减小环路面积
- 地线旁路电容去耦（作为本地电荷池，瞬间提供开关所需的小电流）
- 多根地线并联减小电感

## 五、信号接地分类（P177）

按电路信号特性，信号接地分为四类，每类可能采用不同的接地方式：

### 1. 敏感信号和小信号电路接地

| 典型电路 | 特点 |
|---|---|
| 电流采样/毫伏级信号 | 电平极低，极易受干扰 |
| 麦克风、光电二极管 | 微弱信号传感器 |
| ADC 前端输入 | 直接决定转换精度 |
| 差分放大、仪用放大器 | 高共模抑制比要求 |
| 基准电压源 | 为系统提供参考，纹波敏感 |
| 晶振输出、时钟同步信号 | 时序精度依赖信号质量 |

> 设计要点：接地导线应避免混杂于其他电路中。

### 2. 非敏感信号或大信号电路接地

| 典型电路 | 特点 |
|---|---|
| 功放输出、大功率DAC | 大信号，不易受干扰 |
| 普通IO口 | 数字信号，噪声容限高 |
| 低速 UART、I2C、SPI | 通信速率低，抗干扰较强 |
| 按键扫描 | 无模拟信号 |

> 设计要点：接地电流较大，容易通过耦合对小信号电路造成干扰，必须分开走线。

### 3. 产生强电磁骚扰的设备和接地

| 典型器件 | 骚扰特征 |
|---|---|
| DC-DC、开关稳压管、反激/正激电源 | 高频开关噪声 |
| 功率MOS管、续流二极管 | 快速切换的 di/dt、dv/dt |
| 共模电感 | 本身抑制但也可能是骚扰源 |
| 直流电机、继电器 | 火花、冲击电流 |
| 高速MCU、高频时钟 | 频谱丰富的电磁骚扰 |

> 设计要点：必须将其接地导线与其他电子电路接地导线分开，必要时加屏蔽。

### 4. 金属构件接地

> 机箱、散热器、金属外壳等，主要作用是安全防护和屏蔽，需与安全地（PE）可靠连接。

![信号接地分类 — P177](/images/uploads/pcb-grounding/p177-signal-grounding.jpg)

## 六、设计总结

| 设计决策 | 推荐做法 |
|---|---|
| 降低地线阻抗 | 加粗、缩短、多根并联 |
| 降低走线电感 | 优先加宽走线（比加厚更有效） |
| 高频电路 | 考虑趋肤效应，增加表面积 |
| 精密 ADC | 关注导线压降（nV 级别） |
| 接地布局 | 敏感/大信号/骚扰源四类分离 |
| 地弹抑制 | 减小环路面积 + 去耦电容 |
