## 为什么要自己做波形发生器

普通的定时器 + GPIO 翻转只能输出固定占空比的方波，想要任意时序（多通道、可变脉宽、自定义边沿）只能靠 CPU 翻转引脚——频率一高就崩。真正的解法是让定时器触发 DMA，DMA 把内存里的 BSRR 值直接搬到 GPIO 寄存器，CPU 完全不参与。

## TIM2 + DMA + BSRR 波形引擎

TIM2 的 Update 事件触发 DMA1_Stream0，把内存中的 `GPIOA_BSRR` 写入值搬运到 `GPIOA->BSRR`。每个 BSRR 值可以同时置位 / 复位多个引脚，一个数组就能描述多通道波形。

频率计算：DMA 双缓冲 `[SET PA0, RESET PA0]` 需要 2 次 Update 构成 1 个方波周期。要输出 1 kHz，TIM2 更新频率应为 2 kHz，ARR = 64 MHz / 2 kHz − 1 = 31999。

```c
hdma_tim2_up.Init.Mode = DMA_CIRCULAR;     // 循环模式
hdma_tim2_up.Init.PeriphDataAlignment = DMA_PDATAALIGN_WORD;
hdma_tim2_up.Init.MemDataAlignment = DMA_MDATAALIGN_WORD;
```

**必须用 `HAL_DMA_Start` 而非 `HAL_DMA_Start_IT`**：`Start_IT` 开启传输完成中断，若 DMA 中断优先级高于 SysTick，`HAL_Delay` 会死等。

多通道扩展：`s_waveBuf` 每个元素控制 PA0/PA1/PA2/PA3/PA5 共 5 位，运行时修改 TIM2_ARR 即可动态变频。

## 安全审计：防御性设计

2026-06-30 做了一次全链路安全审计，覆盖固件侧和上位机侧。

### 固件侧

**独立看门狗 (IWDG)**：寄存器级直接操作 IWDG1，不依赖 HAL。LSI ~32 kHz，预分频 256，重装载 500 → 超时约 4 秒。放在 `BSP_Clock_Init()` 之后、`gpio_init()` 之前，主循环卡死 4 秒后自动复位，复位后 GPIO 默认浮空。

**删除上电自启动**：删除 `APP_Run()` 中默认 1kHz 方波的自动启动代码。上电后波形引脚保持浮空输入，必须经上位机显式下发「配置 → 数据 → 开始」。

**软件超时看门狗**：`WAVE_TIMEOUT_MS = 60000u`（60 秒），主循环每轮检测运行时长，超时自动调用 `DRV_WaveGen_Stop()`。

**波形参数校验**：`CMD_WAVE_CONFIG` 拒绝 `ch_mask == 0` 或包含保留位；`CMD_WAVE_DATA` 在 `num_words > DRV_WAVE_MAX_POINTS` 时返回失败，不再静默截断。

**BSRR 安全停止**：原顺序是 TIM 停止 → 关 DMA 更新 → DMA 停止 → 切 INPUT。新顺序改为 **DMA 停止 → BSRR 拉高所有启用通道 → TIM 停止 → 关 DMA 更新 → 切 INPUT**，避免引脚停留在最后驱动电平（常为低）。

**全零 BSRR 检测**：`DRV_WaveGen_LoadData()` 遍历 `data[0..len-1]`，全零返回 false；若 `ch_mask != 0`，检查每个启用通道至少有一次 HIGH，否则返回 false。

**LED 前置拉高**：`BSP_GPIO_WritePin(LED, high)` 移到 `GPIO_InitPin` 之前，避免初始化瞬间低电平脉冲。

### 上位机侧

**波形风险检测**：检测任意通道低电平占比 100%、> 80%、或连续 16 个以上采样点所有通道同时为低 → 弹出 Yes/Cancel 确认框。

**触发时机**：规则应用前、Excel 导入后、下发前三次检测。

**默认值安全化**：新增行默认值 `"0"` → `"1"`，非法输入默认值 `"0"` → `"1"`。

## BSRR Edge=0 零跳变 Bug

波形时序规则在 SCLK init=低 / edge=下降沿且触发边沿序号=0 时，硬件输出全低电平，上位机无任何报错。

根因：`_edge_to_sample(0) = 0` 且 width 覆盖整个 buffer 时，所有样本都是高 → 零电平跳变 → BSRR 中无任何该通道的控制位 → GPIO 保持在 boot 默认（低）。BSRR 生成逻辑只在 `curr ≠ prev` 时生成 BS/BR 位，全恒定电平不产生任何位。

"先配非零 edge 再配 edge=0" 能成功，是因为第一次配置已经把物理引脚拉高，第二次无跳变不产生 BSRR 位，但物理上已经是高。

修复：在 `_get_bsrr_masks()` 末尾新增零跳变通道检测，对无跳变的通道在首个 mask 中强制置高或置低。

固件侧防御：`APP_WaveGen_Start()` 中添加 `HAL_DMA_Abort(&hdma_tim2_up)`，默认波形启动改用 `APP_WaveGen_LoadData()` + `APP_WaveGen_Start()`，避免绕过状态管理。

## 关键经验

1. **BSRR 生成不应纯依赖跳变**：目标波形全为同一电平时必须显式初始化。
2. **DMA 状态机一致性**：固件启动应统一使用框架函数，避免绕过状态管理。
3. **调试需要数据层 dump**：注入 BSRR[0:5] 诊断日志可快速定位配置异常。
4. **模拟开关默认 CLOSE**：PA0 等引脚的模拟开关默认导通，会把波形输出短路到地，必须 `SYSCFG_AnalogSwitchConfig(PA0, OPEN)`。
5. **HSI 也能跑 550 MHz**：板载无 HSE 晶振时，纯 HSI 64 MHz 方案完全可行，不必死磕 PLL。
