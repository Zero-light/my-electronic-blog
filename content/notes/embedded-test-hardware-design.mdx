## 一、电源完整性（Power Integrity）

### Q01 — 为什么需要多层去耦电容？

**📐 L1　💡 高频：是　🔗 关联：07-Q01（低功耗）、08-Q08（ADC 噪声）**

**场景**：你的 ADC 采样值有噪声，检查发现电源纹波较大。

**答案**：
```
去耦电容的作用：
1. 为 IC 瞬态电流提供本地储能，减少电源环路电感的影响
2. 滤除高频噪声，防止噪声通过电源耦合到其他电路
3. 降低电源阻抗，维持电压稳定

多层去耦的原因：
- 大电容（10μF~100μF）：滤除低频纹波，提供大电流储能
- 中电容（100nF）：滤除中频噪声（1MHz~100MHz）
- 小电容（1~10nF）：滤除高频噪声（>100MHz）

实际布局：
- 每个 VDD/VSS 引脚对就近放置 100nF 陶瓷电容
- 电源入口放置 10μF 钽电容或电解电容
- 电容的 GND 端直接连接到完整地平面
```

### Q02 — 去耦电容的布局原则

**📐 L1　💡 高频：是　🔗 关联：09-Q01**

**场景**：你的去耦电容没有起到预期效果。

**答案**：
```
关键布局原则：
1. 尽量靠近芯片引脚（&#60;5mm）
2. 电容的电源端通过最短走线连接到 VDD 引脚
3. 电容的 GND 端通过过孔直接连接到地平面
4. 避免电容与芯片之间有过孔或长走线
5. 多个电容并联时，小电容最靠近芯片

错误示例：
[VIA]---[长走线]---[电容]---[长走线]---[芯片引脚]
→ 走线电感抵消了电容的高频滤波效果

正确示例：
[芯片引脚]---[短走线]---[电容]---[过孔]---[地平面]
→ 最小化电源环路面积
```

### Q03 — LDO 与 DC-DC 的选择

**📐 L1　💡 高频：是　🔗 关联：07-Q01（低功耗）**

**场景**：你需要为 STM32 设计供电电路。

**答案**：

| 特性 | LDO | DC-DC |
|------|-----|-------|
| 效率 | 低（压差大时更差） | 高（80%~95%） |
| 输出噪声 | 低 | 高（开关噪声） |
| 纹波 | 极低 | 需要 LC 滤波 |
| 发热 | 大（压差×电流） | 小 |
| 成本 | 低 | 高 |
| 适用场景 | 模拟供电、低功耗 | 大电流、高效率 |

```
典型方案：
- 电池供电（3.7V 锂电 → 3.3V）：LDO（压差小，噪声低）
- 12V → 3.3V 大电流：DC-DC（效率高，发热小）
- 混合方案：DC-DC 降压到 3.5V → LDO 稳压到 3.3V（兼顾效率和噪声）
```

### Q04 — 电源平面与地平面的设计

**📐 L2　💡 高频：否　🔗 关联：09-Q01、09-Q02**

**场景**：你的 4 层 PCB 需要规划层叠结构。

**答案**：
```
4 层 PCB 典型层叠：
Top Layer：信号 + 元件
Inner 1：完整地平面
Inner 2：电源平面（可分割为多个电源区域）
Bottom Layer：信号 + 元件

关键原则：
1. 地平面必须完整，不要分割
2. 电源平面可以按电压域分割
3. 高速信号线参考完整地平面
4. 模拟地和数字地在 ADC/DAC 处单点连接
5. 避免信号线跨越电源分割区域
```

## 二、复位电路

### Q05 — 外部复位电路设计

**📐 L1　💡 高频：是　🔗 关联：02-Q13（复位类型）、07-Q01**

**场景**：你需要为 STM32 设计可靠的复位电路。

**答案**：
```
STM32 的 NRST 引脚：
- 低电平有效（外部复位）
- 内部有弱上拉电阻（约 40kΩ）
- 需要外部 RC 电路实现上电复位和手动复位

典型电路：
        VDD
         │
        [R1] 10kΩ
         │
NRST ────┴────[C1] 100nF────GND
         │
        [按键]（手动复位）

工作原理：
- 上电时，C1 未充电，NRST = 低电平 → 复位
- C1 通过 R1 充电，NRST 上升到高电平 → 复位结束
- 时间常数 τ = R1 × C1 = 10kΩ × 100nF = 1ms
- 按键按下时，C1 放电，NRST 拉低 → 手动复位

注意：
- 电容值不能太大，否则复位时间过长
- 电容值不能太小，否则抗噪能力差
- 推荐：10kΩ + 100nF
```

### Q06 — 复位电路的 ESD 防护

**📐 L2　💡 高频：否　🔗 关联：09-Q05、09-Q10**

**场景**：你的设备在干燥环境下容易被静电损坏复位电路。

**答案**：
```
复位引脚 ESD 防护：
1. 在 NRST 引脚附近放置 TVS 二极管
2. TVS 的钳位电压应高于 VDD 但低于 MCU 绝对最大值
3. 复位按键的走线尽量短，避免天线效应
4. 复位信号线远离板边和高噪声源

推荐器件：
- TVS：ESD9B5.0ST5G（5V 双向）
- 或集成 ESD 保护器件（如 PRTR5V0U2X）
```

## 三、时钟晶体

### Q07 — 晶体（Crystal）与振荡器（Oscillator）的区别

**📐 L1　💡 高频：是　🔗 关联：02-Q07（时钟树）**

**场景**：你需要为 STM32 选择外部高速时钟源。

**答案**：

| 特性 | 晶体（Crystal） | 振荡器（Oscillator） |
|------|----------------|---------------------|
| 是否需要驱动电路 | 是（MCU 内置反相器） | 否（自带驱动） |
| 成本 | 低 | 高 |
| 精度 | 取决于负载电容 | 高（工厂校准） |
| 启动时间 | 较长 | 短 |
| 功耗 | 低 | 较高 |
| 适用场景 | 大多数应用 | 高精度时序、快速启动 |

### Q08 — 晶体负载电容计算

**📐 L2　💡 高频：是　🔗 关联：09-Q07**

**场景**：你选择了一个 8MHz 晶体，需要计算负载电容值。

**答案**：
```
晶体负载电容计算公式：
CL = (C1 × C2) / (C1 + C2) + Cstray

其中：
- CL：晶体规格书中的负载电容（如 20pF）
- C1, C2：外部负载电容（通常 C1 = C2）
- Cstray：PCB 走线寄生电容（通常 2~5pF）

计算示例：
晶体规格：CL = 20pF
Cstray = 3pF（估计值）
C1 = C2 = C

20pF = (C × C) / (2C) + 3pF
20pF = C/2 + 3pF
C = 34pF

实际选择：选择最接近的标准值 33pF 或 36pF

注意：
- 负载电容偏差会导致频率偏移
- 高精度应用需要实测频率并微调
- 不同 PCB 布局的 Cstray 不同
```

### Q09 — 晶体电路布局要点

**📐 L2　💡 高频：否　🔗 关联：09-Q07、09-Q08**

**场景**：你的晶体起振不稳定，偶尔停振。

**答案**：
```
布局原则：
1. 晶体尽量靠近 MCU 的 OSC_IN/OSC_OUT 引脚
2. 负载电容放在晶体和 MCU 之间，靠近晶体
3. 晶体下方不要走其他信号线
4. 晶体周围铺地（Guard Ring），但不要形成闭合环路
5. 避免晶体靠近高电流走线或开关信号

常见错误：
- 晶体走线过长 → 增加寄生电容和 EMI 敏感度
- 晶体下方走数字信号 → 耦合噪声导致时钟抖动
- 负载电容值不匹配 → 频率偏移
```

## 四、ESD 防护

### Q10 — ESD 防护设计基础

**📐 L1　💡 高频：是　🔗 关联：09-Q06**

**场景**：你的设备在 ESD 测试中（接触放电 ±4kV）复位或损坏。

**答案**：
```
ESD（静电放电）防护设计：
1. 接口防护：
   - USB、UART、CAN 等外部接口必须加 TVS 二极管
   - TVS 的钳位电压应低于被保护器件的最大耐压
   - TVS 尽量靠近接口连接器

2. 外壳防护：
   - 金属外壳接地
   - 塑料外壳内部加导电涂层或金属屏蔽
   - 缝隙和开口尽量小

3. PCB 设计：
   - 信号线远离板边（>2mm）
   - 地平面延伸到板边
   - 关键信号线加串联电阻（限流）

TVS 选型：
- 工作电压 > 信号电压
- 钳位电压 < 被保护器件最大耐压
- 结电容 < 信号允许的容值（高速信号需低电容 TVS）
```

---

### Q11 — USB 接口的 ESD 防护

**📐 L2　💡 高频：否　🔗 关联：09-Q10、04-Q19**

**场景**：你的 USB 设备在插拔时容易损坏。

**答案**：
```
USB ESD 防护：
1. 在 D+、D- 线上加低电容 TVS 二极管阵列
   - 结电容 < 1pF（USB 2.0 高速 480Mbps）
   - 如：PRTR5V0U4D、USBLC6-2SC6

2. VBUS 防护：
   - 5V TVS 或稳压管
   - 可恢复保险丝（过流保护）

3. 布局：
   - TVS 尽量靠近 USB 连接器
   - 差分线等长、等距
   - 差分阻抗 90Ω ±15%
```

## 五、信号完整性

### Q12 — 高速信号线的阻抗控制

**📐 L2　💡 高频：否　🔗 关联：09-Q04**

**场景**：你的 USB 或以太网信号眼图不达标。

**答案**：
```
阻抗控制：
- USB 差分阻抗：90Ω ±15%
- 以太网差分阻抗：100Ω ±10%
- 单端信号（如时钟）：50Ω

影响阻抗的因素：
1. 走线宽度
2. 走线到参考平面的距离
3. 介质的介电常数（FR4 约 4.5）
4. 走线边缘的铜厚

计算工具：
- Saturn PCB Toolkit（免费）
- Polar Si9000（专业）
- PCB 厂商通常提供阻抗计算服务

关键：
- 告诉 PCB 厂商目标阻抗，他们会调整线宽和层叠
- 高速信号线下方的地平面必须完整
```

### Q13 — 串扰（Crosstalk）的抑制

**📐 L2　💡 高频：否　🔗 关联：09-Q04**

**场景**：你的 ADC 采样线旁边有 PWM 走线，采样值有周期性噪声。

**答案**：
```
串扰抑制方法：
1. 增加走线间距（3W 规则：间距 ≥ 3 倍线宽）
2. 敏感信号线用地线隔离（Guard Trace）
3. 缩短平行走线长度
4. 敏感信号线走在内层（带状线），外层有地平面屏蔽
5. 避免 90° 拐角（用 45° 或圆弧）
6. 模拟信号和数字信号分层走线
```

## 六、PCB 设计基础

### Q14 — 模拟地与数字地的处理

**📐 L1　💡 高频：是　🔗 关联：09-Q04、08-Q08**

**场景**：你的 ADC 采样值有数字噪声耦合。

**答案**：
```
模拟地（AGND）和数字地（DGND）处理：

方案 1：单点连接（推荐）
- 模拟地和数字地在 ADC 芯片下方或电源入口单点连接
- 模拟信号走模拟地区域
- 数字信号走数字地区域
- 避免数字电流流过模拟地区域

方案 2：分割地平面
- 将地平面分为模拟和数字两个区域
- 在电源入口或 ADC 处单点连接
- 注意：分割地平面可能导致返回电流路径不连续

方案 3：统一地平面（现代推荐）
- 使用完整地平面
- 通过布局分区（模拟区、数字区）减少耦合
- 确保返回电流路径连续

关键原则：
- 返回电流总是走阻抗最低的路径（直接在信号线下方）
- 地平面不连续会导致返回电流绕路，产生 EMI
```

### Q15 — 热设计考虑

**📐 L2　💡 高频：否　🔗 关联：09-Q03**

**场景**：你的 LDO 或 DC-DC 芯片过热。

**答案**：
```
热设计要点：
1. 计算功耗：P = (Vin - Vout) × I（LDO）或 P = Pin × (1-η)（DC-DC）
2. 了解芯片的热阻（θJA、θJC）
3. 计算结温：Tj = Ta + P × θJA
4. 如果 Tj 超过最大额定值，需要：
   - 增加铜皮面积（散热焊盘）
   - 添加散热过孔（Thermal Via）
   - 使用散热片
   - 降低功耗（如改用 DC-DC）

PCB 散热设计：
- 电源芯片下方铺大面积铜皮
- 使用多个过孔连接顶层和底层铜皮
- 避免将热敏元件放在发热元件附近
```

### Q17 — 连接器选型要点

```
连接器选型考虑因素：
```

## 八、硬件调试与故障排查

### Q18 — 上电无反应的排查流程

**📐 L1　💡 高频：是　🔗 关联：08-调试案例**

**答案**：
```
排查步骤：
1. 测量电源电压
   - VDD 是否在规格范围内（如 3.3V ±5%）
   - 电源纹波是否过大（&#60;50mV 峰峰值）
   - 电源时序是否正确（部分 MCU 要求核心电压先于 IO 电压）

2. 检查复位信号
   - NRST 引脚电平（应为高电平）
   - 复位电路 RC 值是否正确
   - 是否有外部复位芯片

3. 检查时钟
   - 用示波器测量晶振是否起振
   - 时钟频率和幅值是否正确
   - 如果使用内部时钟，确认配置

4. 检查 Boot 引脚
   - BOOT0/BOOT1 电平是否正确
   - 是否意外进入了 Bootloader

5. 检查调试接口
   - SWDIO/SWDCK 连接是否正确
   - 是否被复用为 GPIO
   - 尝试连接调试器读取内核状态
```

### Q19 — 间歇性故障的排查技巧

**📐 L2　💡 高频：否　🔗 关联：08-Q17**

**答案**：
```
间歇性故障常见原因及排查：

1. 焊接问题
   - 虚焊、冷焊 → 重新焊接或 X 光检查
   - 焊锡桥接 → 显微镜检查

2. 温度相关
   - 热胀冷缩导致接触不良 → 加热/冷却测试
   - 半导体参数温漂 → 温度循环测试

3. 振动相关
   - 连接器松动 → 加固或更换连接器
   -  PCB 变形 → 检查安装和固定

4. 电源问题
   - 电压跌落 → 长时间监测电源
   - 纹波过大 → 检查去耦电容

5. 软件问题
   - 看门狗复位 → 检查喂狗策略
   - 栈溢出 → 检查栈使用
   - 中断丢失 → 检查中断优先级

排查工具：
- 示波器：长时间触发捕获异常
- 逻辑分析仪：捕获数字信号时序
- 万用表：测量静态电压和电阻
- 热成像仪：定位过热元件
```

### Q20 — EMI/EMC 基础

**📐 L2　💡 高频：否　🔗 关联：09-Q04、09-Q13**

**答案**：
```
EMI（电磁干扰）三要素：
1. 源（Source）：产生干扰的电路
2. 路径（Path）：干扰传播的途径
3. 受体（Receiver）：受干扰影响的电路

抑制方法：
1. 抑制源：
   - 降低信号边沿速率（串联电阻）
   - 使用扩频时钟（Spread Spectrum Clocking）
   - 降低开关频率（DC-DC）

2. 切断路径：
   - 屏蔽（金属罩、导电涂层）
   - 滤波（电容、磁珠、共模电感）
   - 接地（低阻抗地平面）

3. 保护受体：
   - 增加噪声容限（差分信号）
   - 隔离（光耦、数字隔离器）
   - 软件容错（CRC、重传）

PCB EMC 设计：
- 高速信号线走在内层（带状线）
- 避免 90° 拐角
- 关键信号线用地线隔离
- 电源入口加共模电感和滤波电容
- 机壳接地
```

## 九、综合设计案例

### Q21 — 一个完整的 STM32 最小系统设计

**📐 L2　💡 高频：否　🔗 关联：贯穿全文件**

**场景**：你需要从零设计一个 STM32F407 最小系统板。

**答案**：
```
最小系统包含：
1. MCU：STM32F407VGT6（LQFP100）
2. 电源：
   - 输入：5V USB 或 5V 外部电源
   - 稳压：AMS1117-3.3（LDO，输出 3.3V）
   - 去耦：每个 VDD 引脚 100nF + 电源入口 10μF
   - 模拟电源：VDDA 通过磁珠连接到 VDD，加 1μF + 10nF 滤波

3. 时钟：
   - HSE：8MHz 晶体 + 2×20pF 负载电容
   - LSE：32.768kHz 晶体（RTC，可选）

4. 复位：
   - RC 复位：10kΩ + 100nF
   - 手动复位按键

5. Boot 选择：
   - BOOT0 通过 10kΩ 接地（默认从 Flash 启动）
   - 可通过跳线接 VDD 进入 Bootloader

6. 调试接口：
   - SWD：SWDIO、SWDCK、GND、VDD
   - 10-pin Cortex Debug Connector

7. 其他：
   - 用户 LED（指示状态）
   - 用户按键（输入）
   - 所有 GPIO 引出到排针
```

### Q22 — 硬件设计 Checklist

**📐 L1　💡 高频：否**

**答案**：
```
原理图检查：
□ 所有 IC 的电源引脚都有去耦电容
□ 去耦电容值正确（100nF 陶瓷 + 10μF 电解）
□ 复位电路 RC 值正确
□ 晶体负载电容计算正确
□ Boot 引脚配置正确
□ 调试接口连接正确
□ 所有未使用的 GPIO 配置为模拟输入或确定电平
□ 外部接口有 ESD 防护
□ 电源电流预算充足

PCB 检查：
□ 层叠结构正确（4 层：信号-地-电源-信号）
□ 地平面完整
□ 去耦电容靠近芯片引脚
□ 晶体走线短且对称
□ 高速信号线阻抗控制
□ 模拟地和数字地正确处理
□ 散热焊盘和过孔
□ 丝印清晰，极性标识正确
□ 安装孔和固定孔
□ 测试点充足

生产检查：
□ 元件封装正确
□ 可制造性（DFM）检查
□ 可测试性（测试点）
□ BOM 完整且可采购
```
