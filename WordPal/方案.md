# WordPal — 英语单词云端养成游戏 完整方案

> 一只专属于你的云端小宠物，学单词就是喂它吃饭，背出一组单词就能换装扮。
> 画面液态玻璃质感，交互强，反馈即时。

---

## 一、为什么这么做

### 1.1 需求本质

英语学习的最大瓶颈是「持续动机」。背单词书、刷词 app 都是被动输入，反馈周期长（考试才见分岔），容易中途放弃。

把「背单词」和「宠物养成」耦合，本质是把**抽象的进步（词汇量增长）翻译成可见的反馈（宠物吃饱、变好看、解锁新能力）**，实现：

- **即时反馈**：每背完一个词 → 宠物立刻反应（叫声/动作/粒子）
- **延迟满足**：攒够一周解锁「冬日毛衣」装扮 → 长线留存
- **损失厌恶**：三天不学 → 宠物会「饿瘦」 → 推动返访

### 1.2 为什么选 Phaser 4

- **纯 Web** — 零安装、微信/浏览器都能打开，分享链接即玩
- **Beam Renderer** — Phaser 4 新 WebGL 渲染器，可做玻璃质感折射/模糊
- **Skills 已就位** — 20 个 Claude Code skills 已装好，从架构到编码全链路可用
- **强 TypeScript** — 学习系统数据量大，TS 的类型安全减少 bug

### 1.3 为什么不直接用 Three.js/React

- Phaser 是真正的游戏引擎 — 场景管理、动画状态机、Arcade Physics 内置
- 宠物养成有大量「点击反馈 → 动画 → 音效」循环，Phaser 比手写 React 状态机高效得多
- 长远如果要做「宠物跑酷小游戏」（扩展玩法），Phaser 直接上

## 二、游戏世界观与核心循环

### 2.1 游戏名：WordPal（词友）

**一句话**：你的单词量 = 宠物的幸福值。

### 2.2 核心循环（Core Loop）

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│   选词包 → 学习/复习 → 答对获得「食物」 → 投喂宠物   │
│       ↑                                        │    │
│       │          ┌─────────────────────────────┘    │
│       │          │                                  │
│       │          ▼                                  │
│       │    宠物成长/变装/解锁新场景                   │
│       │          │                                  │
│       │          ▼                                  │
│       └──── 学习目标达成解锁新词包                     │
│                                                     │
└─────────────────────────────────────────────────────┘
```

**正向反馈闭环**：学 → 得 → 喂 → 看反应 → 想更多学

### 2.3 宠物定义（MVP 阶段）

MVP 只有一种宠物：「Cloudy」（云朵精灵 — 乳白色半透明果冻质感）。

**属性**：

| 属性 | 说明 | 范围 |
|------|------|------|
| 饱食度 | 今天学了单词换来的 | 0~100 |
| 心情 | 答题正确率影响 | 😭😟😐🙂😍 |
| 成长值 | 累计学习量，满了进化 | 0~∞ |
| 干净度 | 每隔几小时下降，提醒你回来 | 0~100 |

**状态机**：
- 饥饿（饱食度 < 20）→ 宠物趴在地上、颜色变淡
- 开心（饱食度 > 60 + 正确率 > 80%）→ 宠物身上冒星星、弹跳
- 成长满 → 播进化动画 → 解锁新外表/背景

## 三、学习系统设计

### 3.1 词汇来源

- 内置 **CETC-4/6 词库**（约 5000 词，分成 50 个词包 × 100 词/包）
- 每个词包含：英文、音标、中文释义、例句、发音 URL（有道/金山 API）
- 用户可自定义上传词包（JSON 格式）

### 3.2 学习模式（3 种）

#### A. 新词学习（Learn）

```
┌──────────────────────────────────────┐
│  ┌──────────────────────────────┐    │
│  │     [单词卡正面]             │    │
│  │                              │    │
│  │       ephemeral              │    │
│  │       /ɪˈfem.ər.əl/         │    │
│  │                              │    │
│  │   [🔊 发音]    [翻转 → 释义] │    │
│  └──────────────────────────────┘    │
│                                      │
│  ┌────────────────────────────────┐  │
│  │  "The beauty of cherry        │  │
│  │   blossoms is ___."           │  │
│  └────────────────────────────────┘  │
│                                      │
│  [短暂的]  [永久的]  [美味的]  [巨大的] │
│                                      │
│  进度 ●●●○○○○○○  剩余本组: 8/20     │
└──────────────────────────────────────┘
```

#### B. 复习模式（Review）— SM-2 变体

- 用户答错 → 该词在 1 分钟后再次出现
- 答对 → 间隔 ×2（1分 → 2分 → 4分 → 1天 → 3天...）
- 每天需要回来「打卡」复习 → 宠物等你的食物

#### C. 挑战模式（Challenge）— 限时 60 秒

- 连续看英文选中文 / 看中文选英文
- 连击 5 题 → 额外奖励「金苹果」（宠物最爱，加 30 饱食度）

### 3.3 奖励映射

| 学习行为 | 奖励 |
|----------|------|
| 答对 1 个新词 | 普通食物 ×1（+5 饱食度）|
| 本轮全对 | 宠物零食 ×1（+15 饱食度）|
| 完成一组（20词）| 装扮碎片 ×1 / 新背景解锁 |
| 连续 7 天打卡 | 限定装扮 |
| 连续答对 10 题 | 彩虹金苹果（+50，触发全屏粒子特效）|

## 四、UI 设计 — 液态玻璃

### 4.1 设计语言

**关键词**：通透、柔软、圆润、微动效、柔和渐变

具体实现（Phaser 4 Beam Renderer 能力）：

| 元素 | 实现 |
|------|------|
| 背景 | 多层渐变 + 缓慢移动的模糊光斑（Parallax 2层）|
| 卡片背景 | `Graphics` 绘制圆角矩形 + alpha 0.15 填充 + 白色边缘高光 |
| 液态感 | 所有方块的 cornerRadius ≥ 16；关键容器用贝塞尔曲线做「水滴形」|
| 模糊折射 | `Phaser.FX.Blur` 给背景层加 FX，前景保持清晰（模拟毛玻璃）|
| 按钮按压缩放 | Tween 给按钮做 scale 0.92 → 1.05 → 1.0 的「果冻回弹」曲线 |
| 颜色 | 主色：#7C9CF8（柔紫蓝）→ #B8E6FF（浅湖蓝）；辅助：#FFE5F1 淡粉 |
| 字体 | 标题：Fredoka Rounded；正文：Nunito；都走 WebFont 加载 |

### 4.2 界面结构

游戏只有 3 个场景（Scene）+ 1 个 HUD 覆盖层：

```
┌─────────────────────────────────────────┐
│  HUD Layer (固定置顶)                    │
│ ┌─────┐                 ┌────┐ ┌────┐ │
│ │金币 │   饱食度条❤️     │⚙️  │ │🛒  │ │
│ └─────┘                 └────┘ └────┘ │
├─────────────────────────────────────────┤
│                                         │
│              Game Scene                 │
│     (宠物 + 背景 + 卡片 + 互动元素)       │
│                                         │
└─────────────────────────────────────────┘
│  Bottom Navigation (绝对定位)            │
│    🏠    📖    🎮    🛒    👤           │
│    家   学习  小游戏  商店  我的          │
└─────────────────────────────────────────┘
```

### 4.3 各界面一览

- **家（Home）**：宠物站在「草地小岛」上，可以拖拽摸它（Arcade 物理 + 嘴部判定点触发「开心」表情）
- **学习（Study）**：单词卡从右侧滑入，选项按钮果冻反馈
- **小游戏（Play）**：宠物跑酷小游戏（学完一组解锁 1 次，每次 60 秒，吃到字母加分）
- **商店（Shop）**：装扮分类 — 帽子/领结/背景/宠物染色
- **我的（Me）**：学习统计（已连续天数、总计词汇量、宠物成长图鉴）

## 五、宠物交互系统

### 5.1 交互事件表

| 用户行为 | 宠物反应 | 技术实现 |
|---------|---------|---------|
| 点击身体 | 弹跳 + 抖动 + 心形容器弹出 | Tween scale + Particle emitter |
| 长按拖拽 | 被拎起来，眼睛睁大跟随鼠标 | Arcade body + pointer 监听 |
| 喂食 | 张嘴 → 咬合 → 吞咽动画（scaleY 压扁复原）| Animation 关键帧 + tween |
| 答错 | 趴下、耳朵耷拉、灰色滤镜 | 切换 state + Pipeline 切换 |
| 答对 | 转圈 + 星星迸发（约 20 帧） | Particle burst + spin tween |
| 进化 | 缩成球 → 发光膨胀 → 展开新形态 | 精心编排的 tween 序列 + 闪光 Shader |

### 5.2 宠物动画状态机

```
          ┌─→ idle（呼吸起伏）
          │      ↓ 被点击
          │   happy（弹跳）
          │      ↓ 3秒无互动
          │   idle
          │
sleeping ─┤      ↓ 喂食
          │   eating（咀嚼）
          │      ↓ 吃完
          │   satisfied（满足趴着）
          │
          │      ↓ 答错 3 次
          └─→ sad（灰暗）
                 ↓ 点击 1 次
              idle
```

### 5.3 装扮系统实现

所有装扮都是 **Sprite 帧切换** 或 **叠加 Sprite**：

- **帽子/眼镜/领结** → 作为宠物 Sprite 的子 Container，绑定到 `head` 锚点
- **身体颜色** → 通过 `setTint()` 或自定义 Shader 采样
- **背景更换** → GameScene 内 `bg` 容器切换 textureKey

装扮数据持久化到 `localStorage`（MVP）/ 后端 API（正式版）。

## 六、技术架构

### 6.1 技术栈

| 层 | 选择 | 理由 |
|----|------|------|
| 游戏引擎 | Phaser 4.0.0-rc.7+ | WebGL Beam Renderer + Arcade Physics + Scene 管理 |
| 语言 | TypeScript 5.x | 强类型，Claude Code 验证 |
| 构建 | Vite 5 | HMR 快，Claude Code scaffold 标准 |
| 状态管理 | Phaser Registry + 自定义 EventBus | 够用，不需要 Redux |
| 持久化 | localStorage（MVP）/ IndexedDB | 单词库较大，用 Dexie.js 封 IndexedDB |
| 路由 | 无（单页 Phaser 场景切换）| Phaser Scene 系统本身就是路由 |
| 部署 | Vercel / Cloudflare Pages | 免费 HTTPS + CDN |
| 声音 | Web Audio API + Phaser Sound | 发音 + 点击音效 + 背景音 |

### 6.3 启动流程（main.ts 关键逻辑）

```typescript
const config: Phaser.Types.Core.GameConfig = {
  type: Phaser.WEBGL,           // 必须 WebGL 才能用 Beam + FX
  width: 750,                   // 移动端竖屏
  height: 1334,
  backgroundColor: '#E8F0FF',
  scale: {
    mode: Phaser.Scale.FIT,
    autoCenter: Phaser.Scale.CENTER_BOTH
  },
  scene: [BootScene, HomeScene, StudyScene, MiniGameScene, ShopScene],
  physics: {
    default: 'arcade',
    arcade: { gravity: { x: 0, y: 300 }, debug: false }
  },
  pipeline: [BlurFXPipeline]     // 全局启用 FX Pipeline
}
```
